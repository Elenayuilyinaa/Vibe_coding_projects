## Навигатор управленческого решения

В репозитории два HTML-файла с одним и тем же приложением — интерактивным опросником
из 12 вопросов, который строит профиль принятия управленческих решений по шести
категориям (постановка вопроса, альтернативы, критерии, допущения, риски,
ретроспектива). Это два независимых варианта верстки/реализации одного и того же
экрана, а не разные версии одной программы — оба открываются и работают сами по себе,
без общих файлов.

| | [`navigator.html`](navigator.html) | [`navigator-resheniya.html`](navigator-resheniya.html) |
|---|---|---|
| Рендеринг экранов | Один JS-модуль перерисовывает `#stage` целиком при каждом переходе (`render()` возвращает HTML-строку) | Все пять экранов существуют в разметке сразу, переключение — через показ/скрытие блока `.screen` классом `.active` |
| Экранирование текста | Есть `escapeHtml()`, весь пользовательский/динамический текст экранируется перед вставкой в `innerHTML` | Текст вопросов и материалов вставляется через `innerHTML`/`textContent` без единого правила — местами не экранируется |
| Карта управленческого решения (модалка) | Введённый текст сохраняется в состоянии (`state.mapAnswers`) и восстанавливается при повторном открытии | Поля модалки ни к чему не привязаны — введённый текст теряется при закрытии окна |
| Шрифты | Inter | Manrope (заголовки) + Inter (текст) |

Если нужно внести правку в контент опросника (вопросы, тексты рекомендаций,
материалы библиотеки) — на сегодняшний день её нужно вносить в оба файла отдельно,
так как общего источника данных между ними нет.
